# 🚀 FluxuryApp Beta Deployment Guide

**One-command deployment to AWS with cost optimization for beta testing at `juantheengineer.com/fluxury`**

## 🎯 What You'll Get

- **Cost-Optimized Infrastructure**: ~$22-60/month AWS costs
- **Production-Ready API**: Sessions and beats management
- **Secure Authentication**: AWS Cognito user management
- **Auto-Cleanup**: 90-day TTL to control costs
- **Domain Integration**: Pre-configured for `juantheengineer.com/fluxury`
- **Zero Java Dependencies**: Pure TypeScript CDK deployment

## ⚡ One-Command Deployment

```bash
cd fluxury-infra
./scripts/deploy-beta-code.sh
```

That's it! The script handles everything automatically.

## 📋 Prerequisites

### Required Tools
```bash
# Check Node.js (v18+)
node --version

# Check/install AWS CLI
aws --version
# Install: brew install awscli (macOS) or https://aws.amazon.com/cli/

# Configure AWS credentials
aws configure
```

### AWS Account Setup
- **AWS Account**: With billing enabled and payment method
- **IAM Permissions**: Administrator access (or CDK deployment permissions)
- **Region**: `us-east-1` (recommended) or your preferred region

### Domain Configuration
- **Domain**: `juantheengineer.com` (pre-configured)
- **Hosting**: Squarespace (instructions provided)
- **Optional**: API subdomain `api.juantheengineer.com`

## 🚀 Step-by-Step Deployment

### Step 1: Clone and Prepare
```bash
# Clone repository
git clone <your-repository>
cd FluxuryApp

# Navigate to infrastructure
cd fluxury-infra
```

### Step 2: Run Deployment Script
```bash
# Make script executable (if needed)
chmod +x scripts/deploy-beta-code.sh

# Run one-command deployment
./scripts/deploy-beta-code.sh
```

**The script will:**
1. ✅ Verify all prerequisites (Node.js, AWS CLI, credentials)
2. ✅ Show cost estimates and get your confirmation
3. ✅ Install dependencies and AWS CDK
4. ✅ Build TypeScript code
5. ✅ Bootstrap CDK (first time only)
6. ✅ Deploy AWS infrastructure (5-10 minutes)
7. ✅ Generate environment variables for frontend
8. ✅ Provide next steps for frontend deployment

### Step 3: Deploy Frontend
```bash
# Build frontend for beta
cd ../fluxury-app
npm run build -- --mode beta

# The built files will be in dist/
# Upload these to juantheengineer.com/fluxury
```

### Step 4: Configure Domain (Squarespace)
1. **Upload Files**: Copy `dist/` contents to `/fluxury` folder on your Squarespace site
2. **Optional API Subdomain**: Point `api.juantheengineer.com` to your API Gateway URL
3. **Test**: Visit `https://juantheengineer.com/fluxury`

## 📊 Infrastructure Details

### AWS Resources Created
| Service | Purpose | Cost Impact |
|---------|---------|-------------|
| **API Gateway** | REST API endpoints | ~$5-15/month |
| **Lambda Functions** | Sessions & beats APIs | ~$10-20/month |
| **DynamoDB** | Session metadata storage | ~$5-15/month |
| **S3 Bucket** | File storage with lifecycle | ~$2-10/month |
| **Cognito** | User authentication | Free tier |

### Cost Optimizations
- **Pay-per-request** DynamoDB billing
- **Minimal memory** Lambda functions (256MB)
- **Auto-cleanup** with 90-day TTL
- **Lifecycle rules** for S3 cost control
- **No reserved capacity** or unnecessary features

### Security Features
- **JWT Authentication** via AWS Cognito
- **CORS Configuration** for your domain
- **IAM Roles** with least privilege
- **API Rate Limiting** (100 req/sec)

## 🚨 Troubleshooting

### Deployment Fails

**Issue**: `AWS credentials not found`
```bash
# Solution: Configure AWS CLI
aws configure
aws sts get-caller-identity  # Verify
```

**Issue**: `CDK not bootstrapped`
```bash
# Solution: Bootstrap CDK
cdk bootstrap aws://ACCOUNT-ID/REGION
```

**Issue**: `Permission denied on script`
```bash
# Solution: Make script executable
chmod +x scripts/deploy-beta-code.sh
```

### Frontend Issues

**Issue**: `CORS errors in browser`
```bash
# Solution: Check domain configuration
# Verify origin is listed in beta-stack.ts CORS settings
```

**Issue**: `Authentication doesn't work`
```bash
# Solution: Check environment variables
cat fluxury-app/.env.beta
# Verify User Pool ID and Client ID match AWS Console
```

**Issue**: `API calls fail`
```bash
# Solution: Check API Gateway URL
# Compare .env.beta with CDK outputs
```

### Cost Management

**Issue**: Higher than expected costs
```bash
# Check AWS Cost Explorer
# Review DynamoDB and Lambda usage
# Verify TTL is working (check DynamoDB items)
```

**Issue**: Cleanup not working
```bash
# Check TTL configuration
aws dynamodb describe-table --table-name your-table-name
# Verify S3 lifecycle rules
aws s3api get-bucket-lifecycle-configuration --bucket your-bucket
```
