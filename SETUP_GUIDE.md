# 🚀 FluxuryApp Setup Guide

Complete setup instructions for FluxuryApp development and deployment. Choose your preferred approach below.

## 🎯 Quick Start Options

### **Option 1: Beta Deployment** (Recommended)
Deploy production-ready beta environment in one command:


- **Node.js** (v18 or later)

## 🚀 Beta Deployment (Recommended)

### 1. Prerequisites Check
```bash

node --version  # Should be v18+

# Install/verify AWS CLI
aws --version
# If not installed: brew install awscli (macOS) or visit aws.amazon.com/cli

# Configure AWS credentials
aws configure
# Enter: Access Key, Secret Key, Region (us-east-1), Format (json)
```

```bash
cd fluxury-infra
./scripts/deploy-beta-code.sh
```

```bash

# Upload dist/ contents to juantheengineer.com/fluxury

```

### 4. Access Your Beta App
- **Frontend**: `https://juantheengineer.com/fluxury`
- **API**: Auto-configured and secure
- **User Management**: AWS Cognito with email verification
- **File Storage**: S3 with 90-day auto-cleanup

## 🛠️ Detailed Setup Instructions

For custom development environments or advanced configurations.

### 1. Clone and Install Dependencies

```bash
# Clone the repository
git clone <your-repo-url>
cd FluxuryApp

# Install all dependencies (monorepo setup)
npm install
cd fluxury-app && npm install
cd ../fluxury-infra && npm install
```

### 2. AWS Infrastructure Setup

#### Configure AWS Credentials
```bash
aws configure
# Enter your AWS Access Key ID, Secret, Region (us-east-1), and output format (json)
```

#### Deploy Backend Infrastructure
```bash
cd fluxury-infra

# Option A: Beta deployment (recommended)
./scripts/deploy-beta-code.sh

# Option B: Manual deployment
cdk bootstrap  # First time only
cdk deploy FluxuryBeta
```

### 3. Frontend Configuration

#### Environment Variables
After infrastructure deployment, your `.env.beta` will be auto-generated:

```bash
# Auto-generated by deployment script
VITE_API_BASE_URL=https://your-api.amazonaws.com/beta
VITE_AWS_REGION=us-east-1
VITE_COGNITO_USER_POOL_ID=us-east-1_XXXXXXX
VITE_COGNITO_USER_POOL_CLIENT_ID=xxxxxxxxxx
VITE_S3_BUCKET_NAME=fluxury-beta-files-xxxxx
```

#### Manual Configuration
If setting up manually:

```bash
cd fluxury-app
cp .env.beta .env.local
# Edit .env.local with your AWS values
```

### 4. Start Development

```bash
# Start frontend development server
cd fluxury-app
npm run dev

# The app will be available at http://localhost:5173
```

## 🔥 Common Issues & Solutions

### Issue: CDK Deploy Fails
**Solution**:
```bash
# Check AWS credentials
aws sts get-caller-identity

# Re-bootstrap if needed
cdk bootstrap --force

# Try deploying again
cdk deploy
```

### Issue: Frontend Can't Connect to API
**Symptoms**: API calls fail with CORS or 404 errors

**Solution**:
1. Verify API URL in `.env.local` matches CDK output
2. Check AWS Console → API Gateway for correct endpoint
3. Ensure CORS is configured (should be automatic from our setup)

### Issue: Authentication Doesn't Work
**Symptoms**: Login fails or redirects don't work

**Solution**:
1. Verify Cognito User Pool ID and Client ID in `.env.local`
2. Check AWS Console → Cognito for correct values
3. Ensure no typos in environment variables

### Issue: File Uploads Fail
**Symptoms**: Auto-save shows errors, S3 uploads fail

**Solution**:
1. Check S3 bucket name in `.env.local`
2. Verify IAM permissions for Lambda functions
3. Check CloudWatch logs for detailed error messages

### Issue: Audio Player Doesn't Work
**Symptoms**: Beats don't load or play

**Solution**:
1. Check audio file formats (MP3, WAV supported)
2. Verify S3 bucket CORS configuration
3. Check browser console for audio errors
4. Test with different audio files
